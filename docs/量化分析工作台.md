# Quant 量化分析工作台

## 启动

双击工程根目录 `Quant.bat`，或执行 `powershell -File .\start_quant.ps1`，然后访问 http://127.0.0.1:8600 。保持服务窗口运行。HTML 文件预览不具备数据库/API 服务，不能代替启动程序。

旧工程启动脚本和图表保持原样。本工具从当前 quant 目录的 DuckDB 读取数据，不连接原 OmniSignal 文件夹，不执行交易。

## 两个入口

- 关注雷达：打开时扫描一次默认关注范围（现有指标序列及其他市场行情），提示异常偏离、极端分位、明显变化。可用双列表对话框更改数据与因子，调整参数后点击刷新扫描。关注范围保存在当前浏览器。刷新扫描只重新读取本地数据，不调用上游抓取程序；本版没有后台定时任务。
- 手动分析：分别选择数据、因子，设置日期和参数，运行后查看逐项结果、历史曲线与触发记录。支持将数据/因子/参数/日期保存为浏览器内的方案，以及导出当前结果CSV。

一个数据对应一个或多个因子，每个组合单独解释，不用投票平均把异质因子硬合成交易结论。普通数值序列的变化与统计异常显示“观察”；价格趋势类可以显示偏多、偏空。超买超卖不直接等于反向操作。

## 数据与计算口径

- 原始 OHLCV、已有指标序列通过适配器归一化。股票不同来源与复权口径分开，缺少字段的组合不计算。没有有效成交量的来源不提供量能指标。
- MA 算术平均。EMA 权重 2/(N+1)。SMA(X,N,M) 权重 M/N，首个有效输入初始化。递推时缺失日期不消耗权重，恢复时接上次有效状态；缺失日期本身不输出信号。
- STD 使用总体标准差（除以N）。零分母为无效值，不生成信号。窗口未满显示数据不足；窗口中存在普通漏数显示数据缺失。
- 日历覆盖范围内市场休市日不计数，已确认停牌日计数，价格沿用前收盘、成交量为0。现有 BaoStock 采集流程过滤了停牌记录，历史缺口不能可靠反推停牌，因此不擅自补齐；接入保留 tradestatus=0 或 suspended=true 的数据后会按约定填充。
- 跨市场数据暂无独立完整日历时，按来源观测日期计算并提示限制。日历覆盖不足、数据过期、原始价格不复权会单独提示。
- 分析截止日之后的数据不会用于计算。显示起点之前的历史会参与预热。最新状态对应实际数据日期，过期状态明确标注为历史状态。新鲜度阈值按自然日计，默认7日。
- Z-Score 与日频量比的历史基准不包含当日；历史分位使用中位排名，常数序列为50%。ROC 对普通带负值序列以历史值绝对值为分母。

## 扩展方式

| 模块 | 职责 |
| --- | --- |
| app/analysis/data.py | 数据目录、来源与口径隔离、日历及停牌规范化 |
| app/analysis/operators.py | 平滑、除法、分位等公共算子 |
| app/analysis/factors.py | Factor 注册表：名称、分类、所需字段、参数、预热长度、计算函数、规则和输出标签 |
| app/analysis/rules.py | 指标结果对应的关注规则与方向解释 |
| app/analysis/engine.py | 预热、数据质量门控、当前结果和历史触发记录 |
| app/quant_server.py | 数据目录和分析API，不包含界面逻辑 |
| web/quant/ | 页面布局、双列表选择、参数组件、图表与结果展示 |

新增因子在注册表声明参数及计算函数，参数表单和选择列表会自动显示。计算函数接收带日期索引的 DataFrame 和校验后的参数，返回至少包含 value 列的 DataFrame；函数必须只使用当期及之前的数据，不得 shift(-1) 或用全样本归一化。可复用已有规则，新增规则在 rules.py 中提供解释。新增数据来源在数据适配器中输出统一字段，无须修改各因子。

首批14个因子：MA、EMA、MACD、RSI、ROC、BOLL、Z-Score、历史分位、ATR、KDJ、日频量比、OBV、VR、历史波动率。复杂截面因子和未来收益检验尚未接入；当前历史触发记录不等同于效果回测。
