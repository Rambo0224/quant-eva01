# 复盘面板 Roadmap

## 当前状态

当前工程已经不是单一图表页，而是一个“总面板 + 多模块”的复盘系统。

当前稳定状态：

- 总标题：`复盘面板`
- 模块 1：`流动性面板`
- 模块 2：`有色金属数据`

当前已落地能力：

- DuckDB 存储观测值与图表索引
- FastAPI + Jinja2 网页展示
- 首页卡片缩略图使用 `png`
- 点击“查看交互图”打开 Plotly `html`
- 点击“查看原始数据”打开明细页
- 原始数据支持下载 Excel
- 每个模块有独立时间范围与“刷新数据”
- 模块时间设置持久化到 `config/theme_settings.toml`
- 普通时间序列已改成“数据库增量抓取 + 每次重写 html”
- 财政赤字两张图已切回 FRED

## 当前技术策略

### 普通时间序列

当前采用：

- 数据库尽量只抓最新增量
- 保留历史老数据
- 每次重新写交互图 `html`

目的：

- 减少重复抓取
- 保持页面展示完整历史
- 保证交互图样式变更后能立即生效

### 期现结构

当前采用：

- 动态生成候选合约代码
- 批量查询历史收盘价
- 用最新交易日过滤有效合约
- 取多个时点生成横截面曲线

目的：

- 不手工维护每月合约列表
- 自动应对合约滚动更新

## 已知问题

### 1. DuckDB 占库

现象：

- 后台脚本运行时，网页可能读库失败

当前处理：

- 服务端读取尽量用只读连接
- 读失败时优先返回空结果而不是直接 500

### 2. iFind MCP 模糊匹配不稳定

现象：

- 查询库存、特殊口径、LME 远月时容易串品种
- 长 query 比短 query 更容易跑偏

当前策略：

- 命不中预期列时宁可空白，不画错图
- 对已确认不稳定的口径先不上线

### 3. 交互图缓存与旧文件

现象：

- 浏览器可能继续显示旧的 html

当前策略：

- 交互图链接带 cache token
- 每次运行重写 html
- 必要时重生成现有图文件
