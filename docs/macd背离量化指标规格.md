# A股股票与ETF的 MACD 顶背离、底背离量化指标规格

## 1. 适用范围

对象为沪深 A 股股票和场内 ETF，默认使用日线；算法应允许将同一规则应用于分钟线。每个标的、每个周期独立计算，不能把不同数据源或不同标的混在一起。

## 2. 数据审计结论

当前数据库 `data/replay.duckdb` 中，`equity_daily_bars` 有 8,268,427 条记录，字段包括 `symbol、obs_time、open、high、low、close、volume`，所有记录的 OHLC 均非空。主要覆盖：`baostock_history_k_data` 5,422 个标的（2021-01-04 至 2026-09-02）、`akshare_etf_hist_em` 29 个 ETF（2010-01-04 至 2026-07-20），另有少量 yfinance 和复权数据。

因此，计算 MACD 背离所需的核心字段（标的、日期、收盘价）已经具备，股票和 ETF 均有可用行情。`etf_share_daily` 是 ETF 份额和规模表，不是背离计算的必需输入。

需要程序化时注意：

- 同一股票存在 `000001`、`000001.SZ` 等不同代码形式，必须先统一代码并选定优先数据源，否则会重复计算。
- 数据库没有独立的复权因子；只有约 40 个股票来自 `akshare_stock_zh_a_hist_qfq`。长期回溯应明确使用前复权、后复权或不复权，并在结果中记录口径。
- `amount`、`turnover_rate` 大量为空，但 MACD 背离本身不需要成交额、换手率或成交量。
- 当前没有分钟线表；若要复现文章的 120 分钟、60 分钟或盘口级别分析，必须另行接入分钟数据并按交易时段聚合。

## 3. 基础计算

对每个标的按 `obs_time` 升序去重，使用收盘价 `C_t` 计算：

```text
EMA12_t = EMA(C_t, 12)
EMA26_t = EMA(C_t, 26)
DIF_t   = EMA12_t - EMA26_t
DEA_t   = EMA(DIF_t, 9)
MACD柱_t = 2 × (DIF_t - DEA_t)
```

文章所称“MACD 白线”对应 `DIF`；红、绿角线对应 `MACD柱`。实现应固定 EMA 初始值规则，并在至少 35 根有效 K 线后才输出正式信号。

## 4. 波段定义

以 MACD 柱颜色划分波段：`MACD柱 >= 0` 为红色，`MACD柱 < 0` 为绿色；连续同色柱构成一个波段。相邻波段之间至少有一根相反颜色柱。零值柱必须采用固定规则（建议沿用前一根颜色，首根按后一根颜色），不能在不同运行中变化。

定义波段的代表极值：底背离使用该绿色波段内的收盘价最低值及对应 DIF 最低值；顶背离使用该红色波段内的收盘价最高值及对应 DIF 最高值。若极值有多根 K 线，价格极值取最早发生的 K 线作为锚点，DIF 极值同理并单独记录日期。

## 5. 背离状态机

每个方向维护 `无状态 → 背离开始 → 背离形成 → 有效/失效`，同一时刻只允许一个未结束的候选背离。

### 5.1 底背离

1. **背离开始**：当前 K 线收盘价低于前一个绿色波段的收盘价最低值，且当前 MACD 柱已连续出现至少 2 根绿色柱。记录开始日期、前波段和当前波段。
2. **背离形成（买入提示时刻）**：背离开始后，DIF 出现拐头向上，即 `DIF_t > DIF_{t-1}` 且 `DIF_{t-1} <= DIF_{t-2}`。此时当前价格低点必须低于比较波段价格低点，同时 DIF 当前低点高于比较波段 DIF 低点。
3. **邻峰、隔峰比较**：先与相邻绿色波段比较；若不满足，再与中间隔一个绿色波段的波段比较。比较距离最多为 2 个波段。当前 DIF 低点不得低于所采用比较波段的 DIF 最低值，否则不形成底背离。
4. **失效**：形成后，若后续 DIF 低于邻峰或隔峰的 DIF 最低值，标记 `invalidated`；若在同一绿色波段内 DIF 继续下行并跌破比较极值，也标记失效。

### 5.2 顶背离

1. **背离开始**：当前 K 线收盘价高于前一个红色波段的收盘价最高值，且当前 MACD 柱已连续出现至少 2 根红色柱。
2. **背离形成（卖出提示时刻）**：背离开始后，DIF 出现拐头向下，即 `DIF_t < DIF_{t-1}` 且 `DIF_{t-1} >= DIF_{t-2}`。当前价格高点必须高于比较波段价格高点，同时 DIF 当前高点低于比较波段 DIF 高点。
3. **邻峰、隔峰比较**：先与相邻红色波段比较；若不满足，再与中间隔一个红色波段的波段比较；最多比较 2 个波段。当前 DIF 高点不得高于所采用比较波段的 DIF 最高值，否则不形成顶背离。
4. **失效**：形成后，若后续 DIF 高于邻峰或隔峰的 DIF 最高值，标记 `invalidated`；若在同一红色波段内 DIF 继续上行并突破比较极值，也标记失效。

## 6. 输出字段

每个信号输出：`symbol、frequency、signal_type(top/bottom)、state(started/formed/invalidated)、start_time、formed_time、invalidated_time、price_anchor_time、price_value、dif_anchor_time、dif_value、compare_wave_id、compare_price、compare_dif、wave_distance、source_id、adjustment_mode`。

实时扫描只展示最新状态为 `formed` 且未 `invalidated` 的信号；历史回测必须保留全部状态转移，避免把后来失效的信号误当成有效信号。

## 7. 验证要求

程序完成后至少用人工标注的顶背离、底背离各 3 个案例核对：背离开始日期、形成日期、比较邻峰/隔峰、失效日期。还应检查停牌缺口、涨跌停、除权跳变、重复代码和同日重复记录。结果只表示技术形态，不构成投资建议。
