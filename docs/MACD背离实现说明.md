# MACD 顶底背离

依据 `macd背离量化指标规格.md` 实现，因子 ID 为 `macd_divergence`。

## 使用

手动分析：选择股票或 ETF 行情，在因子对话框“背离”分类中选择“MACD 顶底背离”。

关注雷达：同样可从因子对话框选择；也可点击“股票 / ETF · MACD背离”载入最多40个ETF、20只股票的初始扫描范围，再自行增删数据。这不是全市场扫描；不会改变已有关注方案，只有主动点击快捷按钮才替换范围。

详情展示 DIF、DEA、MACD柱及形成标记，逐条列出开始、形成和失效事件。可导出完整 JSON，包括规格要求的标的、周期、时间、比较波段、价格/DIF锚点、数据来源及复权口径。雷达“值得关注”仅收录当前仍处于 formed 的背离；历史过期数据继续单独标记，未更新行情不会被当作今天的信号。

## 明确的计算选择

- EMA用首个有效价格初始化，缺失时保持上次有效递推状态；默认12/26/9，正式信号至少35根连续有效K线后输出。更长参数使用 `max(35, slow + signal)`。
- 零柱沿用前一根非零颜色；初始零柱暂不分波段。不会使用后一根颜色回填此前状态。
- 每个方向至多保留一个活动候选。每个波段最多形成一次背离；未形成候选在波段结束时标为 invalidated，事件原因会说明是“未形成”，不是已经形成后失效。
- 形成前只使用截至当时的本波段极值，先邻峰再隔峰。价格和DIF极值分别取最早日期。形成时冻结锚点和比较波段，之后不能用波段最终极值改写形成事件。
- 同一根K线可以满足开始与拐头形成条件；先记录 started，再记录 formed。已形成信号跨波段保留，直到DIF严格突破实际选中的比较波段极值。规格中“邻峰或隔峰”据此解释为实际选中的比较对象，不另取未选中的极值。
- 数据缺口会终止候选/有效状态并清空波段比较历史，恢复后重新预热。EMA状态保留；已确认停牌由现有适配器填平价格并计入窗口。未知缺口不推定为停牌。
- 截止日之后的K线先从输入剔除；所有状态转移保存当时快照，不回填未来失效日期到旧的 formed 事件。
- 股票/ETF独立来源行情才能使用此因子；普通情绪序列、接续多源的指数序列不适用。
- 同次请求中同标的多个来源仅计算一份背离，优先级固定为前复权 AkShare 股票、BaoStock 股票/AkShare ETF、BaoStock ETF、其他来源；同级按数据ID固定选择。不会根据未来最新日期或样本长度选择来源。可只选择希望使用的那一个来源来明确指定。
- 状态值1为有效底背离，-1为有效顶背离；0为无有效背离或两方向同时有效，后者方向显示“观察”，详情与 signals 保留两个状态。

## 模块

`app/analysis/divergence.py` 实现独立的逐K线状态机，支持带分钟时间戳的序列。注册表负责参数与字段声明；引擎补充来源、复权和周期信息；API用于来源去重与快捷扫描范围；页面展示完整状态转移。当前数据适配器和产品接口仍为日频，输出 frequency=1d，未声称已经接入分钟行情。

## 验证边界

测试包含顶、底各3组人工写定预期的构造输入（邻峰、平台极值、隔峰），核对开始/形成/失效日期、比较距离和极值锚点；另有逐前缀不变性、未来价格变动、零柱、漏数、预热、API双入口与重复代码去重测试。

这些构造案例用于检验规则，不是人工标注的真实股票行情。真实行情接口冒烟验证与人工逐图标注属于不同验证层级；尚需收集顶底各3个人工标注实盘案例进行对照验收。涨跌停按实际收盘价处理，不复权与除权跳变沿用数据质量提示，不推断缺失复权因子。
