# OmniSignal 数据源策略

`Terminal` 只读；本文件描述 `OmniSignal` 对 A 股指标库的来源优先级。

## 来源优先级

| 来源 | 适用范围 | 定位 | 备注 |
|---|---|---|---|
| iFinD MCP | 历史序列、期货期权、横截面行情和财务指标 | 生产候选 | 使用外部只读配置；不把令牌写入 OmniSignal 仓库 |
| 上交所/深交所官方披露 | 融资融券、交易统计等交易所口径数据 | 首选 | 记录公告/数据日期和修订情况 |
| 中证指数有限公司 | 沪深 300、上证 50、创业板 50、科创 50、中证 500 等指数估值 | 首选 | PE/PB 口径必须记录为静态/动态/TTM 等具体字段 |
| Eastmoney 公开接口 | 涨跌停池、行情快照和部分市场宽度 | 公共回退 | 仅在响应结构校验通过后落库，并保留缓存 |
| AkShare | 对公开数据源的 Python 适配 | 公共回退 | 不把 AkShare 单一接口视为生产级唯一来源 |
| 手工 Excel | 临时补数、接口不可用时的过渡 | 最后回退 | 必须记录文件、工作表、导入时间和覆盖范围 |

## 参考入口

- 同花顺 iFinD：<https://www.51ifind.com/>

## 质量规则

1. 原始数据先落库，再计算合成指标；不在抓取层直接混入派生值。
2. 每条序列保留来源、抓取时间、单位、频率和原始响应摘要。
3. 供应商接口失败时优先使用最近一次通过质量检查的缓存，并在页面显示过期状态。
4. 来源口径不一致时不直接拼接；例如指数估值必须标明估值口径和发布日期。
5. 横截面中位数、分位数和技术面广度必须保留样本数、过滤规则和缺失率。

## 当前核验结果（2026-07-17）

- 上交所融资融券汇总页可以在浏览器端显示字段：信用交易日期、融资余额、融资买入额、融券余量、融券余量金额、融券卖出量和融资融券余额；普通 HTTP 请求抓到的是动态页面壳，适配器必须继续定位真实接口。
- 深交所融资融券入口确认通过 iframe 加载，当前保持未接入，避免把空壳页面当成有效数据。
- iFinD EDB MCP 的初始化和工具发现已成功；iFinD 股票 MCP 的 `get_stock_financials` 已通过单只股票 ROE 查询验证。`get_stock_performance` 的查询语法需要明确指定指标和日频范围后再批量接入。
